# 🫖 Job Genie  
*AI-powered career direction + job discovery for CS students*

## 🚀 Overview  
**Job Genie** is a full-stack web app built in 24 hours at BeaverHacks to help Computer Science students:  
→ choose a career path  
→ find relevant job listings without the overwhelm  

## 🎥 Video Submission

[![Watch our BeaverHacks video submission](https://img.youtube.com/vi/bFP6M8GxT2U/0.jpg)](https://youtu.be/bFP6M8GxT2U)

## ✨ Features  
- 🧠 **AI Career Quiz** → personalized insights + downloadable report  
- 🔍 **Smart Job Board** → auto-filtered listings based on quiz results  
- ⚡ Clean, streamlined UX for faster job discovery  


## 🛠 Tech Stack  
**Frontend:** TypeScript, React, Next.js, Tailwind CSS  
**Backend:** Google Gemini API, FastAPI, Python, Supabase
